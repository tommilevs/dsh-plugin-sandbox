# Sandbox 2.0 Runtime Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the 0.5.x sandbox lifecycle to schema-v3 managed environments whose DSH runtime is physically private to each environment while preserving the existing create/install/start/validate workflows.

**Architecture:** Introduce a small environment-state module and a dedicated DSH runtime provider. Existing `lib/index.js` becomes a thin HTTP/plugin composition layer over a new `SandboxManager`; each environment records an immutable DSH release in `.sandbox/environment.json`, and all DSH commands run through that environment's private `runtime/` tree. A shared `downloads/` directory is cache-only and is never executed directly.

**Tech Stack:** Node.js ESM, `node:test`, Git, pnpm, `@deepseek-ai/dsh`, DSH Web plugin API.

**Spec:** `docs/superpowers/specs/2026-09-16-dsh-plugin-sandbox-2.0-design.md`

## Global Constraints

- Environment manifest schema is exactly `3`.
- Every managed environment owns a physically separate writable DSH runtime tree under `<environment>/runtime/`.
- `downloads/` may cache release/package payloads but is never a runtime execution path.
- Runtime binaries and dependency build output are not committed to environment Git.
- Release identity is immutable (`dsh-vX.Y.Z[-prerelease]`), never `latest` or `next`.
- The provider must verify the private runtime using `dsh --version` and reject a mismatch.
- No operation may silently fall back to the host/global DSH when a private runtime is expected.
- Existing 0.5.x sandboxes must remain recoverable during migration; migration commits only after the private runtime validates.
- STABLE's globally installed/running DSH executable remains externally owned.
- Existing locale contribution and plugin self-update behavior must remain unchanged.

- Create `lib/environment.js` — schema-v3 paths, manifest parsing/writing, environment registry normalization, and legacy-record conversion.
- Create `lib/dsh-runtime-provider.js` — official DSH release catalog, exact package/release mapping, private runtime materialization, and version verification.
- Create `lib/manager.js` — authoritative in-process environment lifecycle for status/create/install/start/stop/snapshot/diff/history/validate/reset/rollback/destroy; later plans extend this class with transactions and AI control.

```js
// lib/environment.js
import { existsSync, mkdirSync, readFileSync, writeFileSync } from 'node:fs'
import { join } from 'node:path'
import { safeId } from './core.js'

export const ENVIRONMENT_SCHEMA_VERSION = 3
const RELEASE = /^dsh-v\d+\.\d+\.\d+(?:-[0-9A-Za-z.-]+)?$/

export function environmentPaths(root, id) {
  const safe = safeId(id)
  const path = join(root, 'environments', safe)
  return {
    id: safe,
    path,
    dshHome: join(path, 'dsh-home'),
    profilePath: join(path, 'dsh-home', 'profiles', 'web'),
    runtimePath: join(path, 'runtime'),
    manifestPath: join(path, '.sandbox', 'environment.json'),
    logsPath: join(path, 'logs'),
  }
}

export function normalizeEnvironmentManifest(value) {
  if (!value || value.schemaVersion !== ENVIRONMENT_SCHEMA_VERSION) throw new Error('Unsupported environment schema')
  if (!RELEASE.test(String(value.dshRelease || ''))) throw new Error('Environment requires an immutable DSH release identity')
  return { schemaVersion: ENVIRONMENT_SCHEMA_VERSION, dshRelease: String(value.dshRelease) }
}

export function writeEnvironmentManifest(path, value) {
  const manifest = normalizeEnvironmentManifest(value)
  const dir = join(path, '.sandbox')
  mkdirSync(dir, { recursive: true })
  writeFileSync(join(dir, 'environment.json'), JSON.stringify(manifest, null, 2) + '\n')
  return manifest
}

export function readEnvironmentManifest(path) {
  const file = join(path, '.sandbox', 'environment.json')
  if (!existsSync(file)) throw new Error(`Environment manifest is missing: ${file}`)
  return normalizeEnvironmentManifest(JSON.parse(readFileSync(file, 'utf8')))
}
```

```js
// lib/dsh-runtime-provider.js
const TAG = /^dsh-v(\d+\.\d+\.\d+(?:-[0-9A-Za-z.-]+)?)$/
export const DSH_REPOSITORY = 'deepseek-ai/deepseek-harness'

export function releaseToVersion(tag) {
  const match = String(tag || '').match(TAG)
  if (!match) throw new Error(`Unsupported DSH release tag: ${tag}`)
  return match[1]
}

export function parseDshRelease(payload) {
  if (!payload || payload.draft) throw new Error('DSH release must be published and non-draft')
  const release = String(payload.tag_name || '')
  return {
    release,
    version: releaseToVersion(release),
    prerelease: Boolean(payload.prerelease),
    publishedAt: payload.published_at || null,
  }
}

export function runtimePackageSpec(release) {
  return `@deepseek-ai/dsh@${releaseToVersion(release)}`
}

export async function fetchDshReleaseCatalog(fetcher, repo = DSH_REPOSITORY) {
  const response = await fetcher(`https://api.github.com/repos/${repo}/releases?per_page=100`, { headers: { accept: 'application/vnd.github+json' } })
  if (!response?.ok) throw new Error(`DSH release catalog unavailable${response?.status ? ` (HTTP ${response.status})` : ''}`)
  const payload = await response.json()
  return payload.filter(item => !item.draft).map(parseDshRelease)
}
```

- [ ] **Step 3: Implement materialization**

Use a dedicated tiny package root per environment. `pnpm add --save-exact` is executed inside `<environment>/runtime`; the executable entry is the installed package's `lib/bin.js` and is invoked with the current Node executable.

```js
// lib/dsh-runtime-provider.js additions
import { existsSync, mkdirSync, rmSync, writeFileSync } from 'node:fs'
import { join } from 'node:path'
import { command } from './core.js'

export async function verifyPrivateRuntime(runtimeSpec, run = command) {
  if (!runtimeSpec?.root || !runtimeSpec?.command || !runtimeSpec?.release) throw new Error('Private DSH runtime spec is incomplete')
  const result = await run(runtimeSpec.command, [...runtimeSpec.args, '--version'], runtimeSpec.root)
  const actual = String(result.stdout || '').trim()
  if (actual !== runtimeSpec.version) throw new Error(`DSH runtime version mismatch: expected ${runtimeSpec.version}, found ${actual}`)
  return actual
}

export async function materializePrivateRuntime({ root, environmentPath, release, run = command }) {
  const version = releaseToVersion(release)
  const runtimeRoot = join(environmentPath, 'runtime')
  rmSync(runtimeRoot, { recursive: true, force: true })
  mkdirSync(runtimeRoot, { recursive: true })
  writeFileSync(join(runtimeRoot, 'package.json'), JSON.stringify({ private: true }, null, 2) + '\n')
  await run(process.platform === 'win32' ? 'pnpm.cmd' : 'pnpm', ['add', '--save-exact', runtimePackageSpec(release)], runtimeRoot)
  const entry = join(runtimeRoot, 'node_modules', '@deepseek-ai', 'dsh', 'lib', 'bin.js')
  if (!existsSync(entry)) throw new Error(`Private DSH runtime entry is missing: ${entry}`)
  const runtimeSpec = { release, version, root: runtimeRoot, command: process.execPath, args: [entry] }
  await verifyPrivateRuntime(runtimeSpec, run)
  return runtimeSpec
}
```

The implementation may populate `<manager-root>/downloads/` through pnpm's store/cache settings, but it must not return a command path under `downloads/`.
